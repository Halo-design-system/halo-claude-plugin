# Halo plugin for Claude Code

The Claude Code plugin for the [Halo design system](https://halo-design-system.github.io/Halo-design-system/): four skills for building, reviewing, theming and migrating React UI with Halo.

```
/plugin marketplace add Halo-design-system/halo-claude-plugin
/plugin install halo-ds@halo-design-system
```

See [plugins/halo-ds/README.md](plugins/halo-ds/README.md) for what it runs and what it reads.

This repository only holds the plugin. Halo itself, including the source of these files, lives in [Halo-design-system/Halo-design-system](https://github.com/Halo-design-system/Halo-design-system), where the plugin is edited in `plugins/halo-ds`. The **Sync** workflow here copies it from each new Halo release.
